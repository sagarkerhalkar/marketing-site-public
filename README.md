# Sagar RMM sales site

Static site for https://rmm.sagarkerhalkar.com. Hosted on Cloudflare Pages from this repository
(no build command, output folder `/`). Source of truth: `marketing/site/` in Sagar-RMM-vNEXT.

| Path | What it is |
|---|---|
| `index.html` | The page, written for owners and CTOs: seven questions, downtime-cost calculator, owner's view, the film, CTO section, live tour, real screens, win-win, pricing, FAQ, demo booking. |
| `img/` | Real Sagar RMM console screens (sample data). |
| `media/owners-film.mp4` | The 83-second film for owners and CTOs shown on the page, with its poster image. `media/problems-solved.mp4` is the earlier film. |

Contact details: edit the `CONTACT` line near the end of `index.html` (WhatsApp number with country code,
and an email if you want one). Until it is filled, the demo form says booking opens once the number is set.
